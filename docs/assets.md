# Asset manifest

All photographic images are illustrative placeholders, not photos of Fayid facilities, suppliers, or actual inventory. Replace with brand-approved photography before public launch if those distinctions matter in context.

- `rack*.webp`: https://images.unsplash.com/photo-1445205170230-053b83016050 — warm garments on hangers. Unsplash license: https://unsplash.com/license.
- `garments*.webp`: https://images.unsplash.com/photo-1489987707025-afc232f7ea0f — colorful garments on hangers. Same Unsplash license. Neither photograph is generated by AI.
- `brand-original.png`: user-supplied `tt.png`.
- `brand-teal.jpg`: user-supplied `f.jpg`.
- `mark.png`: cropped/resized original mark for navigation. White background blends with the page using CSS. No redrawing.
- `og.jpg`: supplied teal logo image placed on matching background for social sharing.
- `arabic-regular.ttf`, `arabic-semibold.ttf`: IBM Plex Sans Arabic from https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic. SIL Open Font License included at `public/fonts/OFL.txt`.

Run `node scripts/prepare-assets.mjs` to regenerate optimized images from source JPEGs and supplied logos. Production image loading is entirely local.

WOFF versions of the fonts are losslessly compressed from the supplied TTF sources. The transparent navigation mark is prepared with node scripts/transparent-mark.mjs.
